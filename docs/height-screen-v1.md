# Objetivo da Tela

Permitir que o usuário registre sua altura de forma simples, rápida e intuitiva.

A altura será utilizada para:

- cálculo de IMC
- personalização metabólica
- projeções de evolução
- ajustes da GLPY IA
- metas realistas de transformação

# Campo Principal

Input digitável centralizado.

Exemplo:

---

# Regras do Campo

- NÃO usar slider
- NÃO usar wheel picker exagerado
- usar campo digitável
- teclado numérico automático
- aceitar:
164
164cm
1.64

Conversão automática interna:
1.64 → 164 cm

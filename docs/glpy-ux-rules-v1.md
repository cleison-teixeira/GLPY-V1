Toda nova tela, fluxo ou feature deve seguir estas regras.

Filosofia Principal do GLPY

O GLPY não deve parecer:

app médico frio
dashboard corporativo
contador de calorias
aplicativo fitness genérico
aplicativo de dieta

O GLPY deve parecer:

"um ecossistema humano de transformação metabólica."

Emoções Oficiais do Produto

Toda experiência precisa transmitir:

1. Acolhimento

O usuário precisa sentir:

"eu estou sendo acompanhado."

2. Evolução

O usuário precisa sentir:

"eu estou melhorando."

3. Continuidade

O usuário precisa sentir:

"não posso abandonar agora."

4. Segurança

O usuário precisa sentir:

"minha jornada está protegida."

5. Pertencimento

O usuário precisa sentir:

"existem pessoas como eu."

Estrutura Oficial de UX
Regra Principal

Cada tela deve ter:

1 objetivo principal
1 ação principal
1 emoção dominante
Nunca criar:
telas confusas
excesso de informações
múltiplos CTAs importantes
excesso de inputs
overload visual
Regras Oficiais do Onboarding

O onboarding deve parecer:

leve
rápido
premium
humano
personalizado

Nunca:

burocrático
longo demais
técnico demais
Estrutura Oficial do Onboarding

Cada tela:

apenas 1 pergunta
progressão clara
animações suaves
sensação de avanço constante
Regras Oficiais de Inputs
Sempre priorizar:
simplicidade
rapidez

Nunca reinventar:
campos de peso
inputs básicos
sliders exagerados
componentes confusos
Regra Oficial Operacional

Telas operacionais devem:

reduzir atrito
aumentar frequência diária
parecer extremamente rápidas
exigir mínimo esforço mental

Regras Oficiais de Retenção

Toda tela deve aumentar pelo menos um dos seguintes:

1. Continuidade

"quero voltar amanhã."

2. Progresso

"estou evoluindo."

3. Identidade

"essa nova versão já é parte de mim."

4. Pertencimento

"não estou sozinho."

Regras Oficiais de Feedback

Toda ação do usuário deve gerar:

confirmação visual
micro recompensa emocional
sensação de progresso
Exemplos:

✅ "Peso atualizado com sucesso"

✅ "Você está evoluindo"

✅ "Mais um passo concluído"

Nunca usar:

❌ mensagens frias
❌ mensagens robóticas
❌ mensagens técnicas demais
